### ✨ What is Sidebar Remover?

**Sidebar Remover** is an ultra-fast, privacy-first Chrome extension that automatically detects and hides sticky sidebars, cluttered nav rails, and floating panels so you can focus on reading what matters.

- ⚡ **Auto-Detection** — Instantly identifies distraction sidebars without breaking site layouts.
- 🔒 **100% Private** — Operates entirely locally in your browser. Zero telemetry, zero tracking.
- 🎛️ **Granular Control** — Toggle per website, customize allowlists/blocklists, or restore hidden panels in one click.
- 🌓 **Premium Charcoal UI** — Sleek dark interface with full scrollbar suppression.

---

### 🚀 How to Install

1. **Clone or Download** this repository:
   ```bash
   git clone https://github.com/witrfaruk/Sidebar-Remover.git
   ```
2. Open Google Chrome and go to `chrome://extensions/`.
3. Enable **Developer mode** using the toggle in the top-right corner.
4. Click **Load unpacked** and select this project directory.
5. Pin **Sidebar Remover** to your Chrome toolbar for instant access!

---

### 🎯 How to Use

1. **Browse Any Website**: Visit blogs, documentation, or news sites. Sidebars are cleaned up automatically.
2. **Open the Extension**: Click the toolbar icon to view detection status and total hidden sidebars.
3. **Toggle Current Site**: Disable or enable removal for specific domains anytime.
4. **Restore or Rescan**: Hit **Restore Hidden** to reveal sidebars temporarily, or **Rescan** to re-evaluate dynamic page changes.
5. **Fine-Tune in Settings**: Expand **More settings** to configure your custom Allowlist, Blocklist, or toggle scrollbar hiding.
